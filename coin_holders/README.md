# Coin holders

Inserts para organizar moedas e marcadores de Pokemon em paginas plasticas de
fichario.

## Modelos parametricos

| Modelo | Status | Descricao |
|---|---|---|
| [pokemon-coin-binder-01](./pokemon-coin-binder-01/) | em andamento | Insert 63 x 88 x 2mm para moeda Pokemon Ø51,4 x 2,7mm; abertura Ø51,8 e chapa de 3 unidades para a A1 mini |
