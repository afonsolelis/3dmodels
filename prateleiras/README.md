# Prateleiras

Prateleiras de parede paramétricas, modeladas em OpenSCAD e impressas na
FlashForge AD5X. A ideia da categoria é prateleira **modular**: uma peça só,
repetida, que vai emendando na parede até o comprimento que o usuário quiser.
