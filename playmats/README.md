# Playmats

Plataformas de jogo (tapetes/campos) montadas a partir de placas que se
encaixam, cada uma cabendo na cama da Bambu A1 mini.

## Por que placas encaixáveis

Um playmat de torneio tem 610x356mm — não cabe em cama nenhuma de
impressora doméstica. A saída é dividir o campo em placas e encaixá-las.
Duas decisões que valem pra qualquer modelo desta categoria:

- **Onde cortar**: a costura entre placas tem que cair dentro de uma parede
  de relevo, nunca no meio de uma cavidade de carta — e a parede precisa ter
  pelo menos 4mm de espessura ali, senão sobra uma lasca de 1mm de cada lado.
- **Como encaixar**: encaixe que exige deslizar em duas direções (tipo
  rabo-de-andorinha nos dois eixos) trava num grid 2D — a segunda placa não
  tem por onde entrar. Meia-madeira com detente resolve: cada placa **desce**
  no lugar, na ordem esquerda→direita, baixo→cima.
