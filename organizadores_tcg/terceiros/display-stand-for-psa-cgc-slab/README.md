**Atenção:** Os 85.00 x 138.52 deste arquivo são o ENVELOPE DO SUPORTE, não o tamanho da slab. O psa-box-01 cita 'my_psa_slab.3mf da silhueta 85.00x138.52' como fonte de largura de slab — isso está errado e inflou a estimativa. A evidência real deste arquivo é um canal de 81.0mm, ou seja, slab MENOR que 81 — o que reforça a variante pequena (81.0 x 133.5) medida no psa-bumper-01 e enfraquece a rotulação de 'OUTLIER' dada ao psa-bumper-02.

Este item é um download de terceiro. A prévia pode mostrar uma foto promocional, uma renderização da malha ou só uma das plates. As medidas consideram cada peça separadamente; confira a disposição das plates e o perfil no Flash Studio antes de imprimir.
